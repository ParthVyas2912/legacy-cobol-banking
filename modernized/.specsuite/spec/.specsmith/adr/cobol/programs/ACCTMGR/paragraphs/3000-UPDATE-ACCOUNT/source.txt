Paragraph: 3000-UPDATE-ACCOUNT (section MAIN-ROUTINE)
Lines: 89-104
Statements: 4

1. MOVE COMM-ACCT-NUMBER TO ACCT-NUMBER
2. EXEC CICS  READ FILE('ACCTFILE')
                   INTO(ACCT-RECORD)
                   RIDFLD(ACCT-NUMBER)
                   UPDATE
                   RESP(WS-RESPONSE-CODE)
     END-EXEC
3. IF WS-RESPONSE-CODE = 0 PERFORM 3100-APPLY-UPDATES EXEC CICS  REWRITE FILE('ACCTFILE')
                          FROM(ACCT-RECORD)
                          RESP(WS-RESPONSE-CODE)
         END-EXEC END-IF
4. IF WS-RESPONSE-CODE = 0 MOVE 0 TO COMM-RESULT-CODE ELSE MOVE 3 TO COMM-RESULT-CODE END-IF
